# Frontend Gym: инструкции для агента

Начни с [docs/PROJECT.md](docs/PROJECT.md): там статус по разделам, карта кода и рецепты добавления уроков, задач и треков. План по этапам в [docs/PLAN.md](docs/PLAN.md).

Обязательно:

- Обновляй `docs/PROJECT.md` в том же PR, что и изменения: статус, пути, рецепты.
- Контент на русском и английском с одинаковой структурой и одинаковым кодом в примерах.
- Объяснение на странице, ссылки на официальные источники только в конце («Читать подробнее»).
- Заметки из Notion содержат ошибки: сверяй каждое утверждение с документацией и запуском, расхождения пиши в `docs/content-audit/<track>.md`.
- Примеры кода в уроках проверяются: ```` ```js run ```` / ```` ```ts run ```` / ```` ```js dom ```` / ```` ```jsx dom ```` (React в jsdom) / ```` ```jsx run ```` с блоком ```` ```output ````, ```` ```ts check ```` и ```` ```tsx check ```` для `tsc --strict`.
- Перед `check:content` прогони `pnpm tsx scripts/quiz-lengths.ts <track>`: правильный ответ в квизе не должен быть заметно длиннее остальных.
- Перед PR: `pnpm test`, `pnpm typecheck`, `pnpm lint`, `pnpm build`, `pnpm check:content`; для новых источников `pnpm check:links`.
- Работай только в этом репозитории. Ветка и PR на каждый блок.
