## Зачем это нужно

Поиск по мере ввода не должен слать запрос на каждую букву. В React задержку удобнее делать не обёрткой над функцией (задача `debounce`), а хуком над значением: компонент рендерится с актуальным текстом в поле, а запрос зависит от отложенного значения. Задача проверяет, как кандидат работает с таймером в эффекте и его очисткой.

## Что сделать

`useDebouncedValue(value, delay)`:

- при первом рендере возвращает `value` сразу;
- когда `value` меняется, возвращает прежнее значение, пока новое не продержится `delay` мс без изменений;
- из серии быстрых изменений до компонента доходит только последнее;
- после размонтирования ничего не обновляет.

## Тесты

Тесты рендерят маленький компонент, который вызывает ваш хук, меняют его проп через `rerender` и ждут реальное время (`sleep`).

## Идея решения

Отложенное значение хранится в состоянии. Эффект с зависимостями `[value, delay]` ставит таймер, который через `delay` записывает `value`. Очистка эффекта снимает таймер, и это вся логика debounce: каждое новое значение сначала вызывает очистку прошлого эффекта (старый таймер отменён), потом ставит новый. При размонтировании очистка тоже сработает, и обновления после удаления компонента не будет.

```tsx
const [debounced, setDebounced] = useState(value)
useEffect(() => {
  const timer = setTimeout(() => setDebounced(value), delay)
  return () => clearTimeout(timer)
}, [value, delay])
```

## Подводные камни

- **Нет очистки.** Таймеры копятся: на экран по очереди приходят все промежуточные значения, а после размонтирования React обновляет удалённый компонент.
- **`useRef` для значения.** Изменение ref не вызывает рендер, поэтому новое значение не появится на экране.
- **Debounce-функция внутри компонента.** `debounce(fn, 300)` в теле компонента создаётся заново на каждом рендере, и задержка не работает (см. задачу `debounce`).

## Что спросят дальше

- Чем это отличается от `useDeferredValue`: тот не ждёт фиксированное время, а откладывает рендер, пока есть более срочная работа, и не уменьшает число запросов.
- Как сделать `useDebouncedCallback`: функция в `useRef` или `useEffectEvent`, таймер в ref, очистка при размонтировании.
- Где ставить debounce для запроса: здесь, в библиотеке данных или на сервере (кэш и rate limit).
