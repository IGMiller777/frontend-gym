## Зачем это нужно

Некоторые события приходят пачками: ввод в поле поиска, `resize` окна, правки в редакторе. Реагировать на каждое дорого: лишние запросы к серверу, лишние перерасчёты. Debounce откладывает вызов, пока события идут, и выполняет его один раз, когда наступила пауза. Классический пример: поиск отправляет запрос через 300 мс после того, как человек перестал печатать.

## Что сделать

`debounce(fn, wait)` возвращает функцию-обёртку:

- каждый вызов обёртки откладывает вызов `fn` на `wait` мс, предыдущий отложенный вызов отменяется;
- `fn` получает аргументы последнего вызова и тот же `this`, с которым вызвали обёртку;
- у обёртки есть метод `cancel()`, который отменяет запланированный вызов;
- после `cancel()` обёртка продолжает работать.

## Пример

```ts
const search = debounce((query: string) => fetchResults(query), 300)
input.addEventListener('input', (e) => search((e.target as HTMLInputElement).value))
// «r», «re», «rea», «reac», «react» быстро подряд → один запрос с 'react'
```

Тесты используют поддельные таймеры: `clock.tick(100)` мгновенно сдвигает время на 100 мс.

## Идея решения

Храним идентификатор таймера в замыкании. При каждом вызове сбрасываем старый таймер через `clearTimeout` и ставим новый. Когда таймер сработал, вызываем `fn` с сохранёнными аргументами.

Обёртка объявлена через `function`, а не стрелкой: так у неё есть свой `this`. Внутри `setTimeout` стоит стрелочная функция, она берёт `this` обёртки, и `fn.apply(this, args)` передаёт его дальше.

`cancel` это просто свойство функции: функции в JavaScript тоже объекты.

## Подводные камни

- **Потерянный `this`.** Если обёртка стрелочная, `this` возьмётся из места, где вызвали `debounce`, а не из объекта, на котором вызвали метод.
- **Обёртка внутри обработчика.** `onInput={() => debounce(save, 300)()}` в React создаёт новую обёртку на каждое событие, и задержка не работает. Обёртку создают один раз: вне компонента, в `useMemo` или в `useRef`.
- **Отмена при размонтировании.** Если компонент удалён, а вызов ещё запланирован, он сработает с устаревшими данными. Для этого и нужен `cancel()`.

## Что спросят дальше

- Чем debounce отличается от throttle (следующая задача).
- Режим `leading`: вызвать сразу на первом событии, а потом молчать до паузы.
- Как вернуть результат `fn` из debounce: обёртка может возвращать промис, который разрешится результатом.
