## Зачем это нужно

Список дел это самая частая задача на live-coding по React. На ней проверяют базу: управляемое поле, форму, неизменяемые обновления массива и ключи списка. Отдельно смотрят, отличает ли кандидат ключ-индекс от настоящего id.

## Что сделать

`<TodoList initial={['Milk']} />`:

- поле с подписью «New task» и кнопка «Add» внутри формы; отправка формы (кнопкой или Enter) добавляет задачу и очищает поле, страница не перезагружается;
- пустое значение и строка из пробелов не добавляются;
- каждая задача это `<li>` с флажком, подписанным её текстом, и кнопкой с `aria-label="Delete <текст>"`;
- под списком строка «N left»: сколько задач не отмечено;
- задачи с одинаковым текстом допустимы и живут независимо.

## Тесты

Тесты рендерят компонент и действуют как пользователь: ищут элементы по роли и подписи (`screen.getByRole('checkbox', { name: 'Milk' })`, `screen.getByLabelText('New task')`), печатают и кликают (`user.type`, `user.click`). Справа можно открыть предпросмотр и попробовать компонент руками.

## Идея решения

Состояние это массив объектов `{ id, title, done }`. Id выдаёт счётчик, а не индекс и не текст: при удалении индексы сдвигаются, а тексты бывают одинаковыми. Начальный список превращается в объекты один раз, ленивым инициализатором `useState(() => ...)`.

Добавление висит на `onSubmit` формы: так работают и кнопка, и Enter в поле. `e.preventDefault()` отменяет перезагрузку страницы. Все изменения массива создают новый массив: `[...list, item]`, `map` для отметки, `filter` для удаления. Счётчик «left» не хранится в состоянии, а считается при рендере.

Флажок завёрнут в `<label>` вместе с текстом, поэтому у него есть доступное имя, и клик по тексту тоже его переключает. У кнопки удаления видимый текст «×», поэтому имя задаёт `aria-label`.

## Подводные камни

- **Ключ-индекс или ключ-текст.** С индексом после удаления первой задачи флажок «съезжает» на соседнюю; с текстом две задачи «Milk» получат одинаковый ключ.
- **Мутация.** `todo.done = !todo.done; setTodos(todos)` не вызовет рендер: ссылка на массив та же.
- **Кнопка без `type`.** Внутри формы `<button>` по умолчанию `type="submit"`: кнопки удаления должны быть `type="button"`, иначе каждая будет отправлять форму.
- **Производное в состоянии.** Отдельный `useState` для счётчика легко рассинхронизировать с списком.

## Что спросят дальше
