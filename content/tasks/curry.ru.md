## Зачем это нужно

Каррирование превращает функцию `f(a, b, c)` в цепочку `f(a)(b)(c)`. На практике это частичное применение: зафиксировать часть аргументов и получить новую функцию. Например, `const logError = log('error')` или `const byId = sortBy('id')`. Задача проверяет замыкания, оператор `...` и свойство `Function.length`.

## Что сделать

`curry(fn)` возвращает функцию, которая:

- копит аргументы между вызовами, пока их не станет не меньше `fn.length`;
- принимает аргументы любыми порциями: `f(1)(2)(3)`, `f(1, 2)(3)`, `f(1)(2, 3)` и `f(1, 2, 3)` дают одно и то же;
- после набора аргументов вызывает `fn` и возвращает результат, лишние аргументы тоже передаёт в `fn`;
- позволяет переиспользовать частично применённые функции: `const inc = add(1)` можно вызывать много раз.

## Пример

```ts
const add = curry((a: number, b: number, c: number) => a + b + c)
add(1)(2)(3)  // 6
add(1, 2)(3)  // 6
const add10 = add(4, 6)
add10(1)      // 11
```

## Идея решения

Функция `curried(...args)` смотрит, хватает ли аргументов. Если да, вызывает `fn(...args)`. Если нет, возвращает новую функцию, которая добавит следующие аргументы к уже накопленным и снова вызовет `curried`.

Сколько аргументов нужно, говорит `fn.length`: число объявленных параметров до первого параметра со значением по умолчанию или rest-параметра.

## Подводные камни

- **Общий массив аргументов.** Если копить аргументы в одном массиве снаружи (`let saved = []`), частичные функции начнут мешать друг другу: `add(1)` и `add(2)` будут писать в одно место. В решении каждый вызов создаёт новое замыкание со своей копией `args`.
- **`fn.length` не всегда честный.** У `(a, b = 1) => …` длина 1, у `(...args) => …` длина 0. Такую функцию `curry` вызовет сразу. Если нужна другая арность, её передают вторым параметром: `curry(fn, 3)`.
- **Ноль параметров.** `curry(() => 42)()` должен сразу вернуть 42: ноль аргументов уже не меньше `fn.length`.
