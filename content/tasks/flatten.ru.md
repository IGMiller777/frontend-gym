## Зачем это нужно

Вложенные массивы появляются постоянно: ответы API по страницам, дерево меню, результаты `map`, где каждый элемент вернул массив. В языке для этого есть `Array.prototype.flat(depth)` (с ES2019), но на собеседовании просят написать его самому. Так проверяют рекурсию, работу с глубиной и знание мелочей вроде дыр в массивах.

## Что сделать

`flatten(arr, depth = Infinity)` возвращает новый массив, в котором вложенные массивы развёрнуты не глубже `depth` уровней:

- исходный массив не меняется;
- `depth = 0` даёт неглубокую копию, вложенные массивы остаются теми же объектами;
- пустые вложенные массивы просто исчезают;
- дыры в разреженных массивах пропускаются, как у `.flat()`;
- встроенный `.flat()` использовать нельзя.

## Пример

```ts
flatten([1, [2, [3, [4]]]])     // [1, 2, 3, 4]
flatten([1, [2, [3, [4]]]], 1)  // [1, 2, [3, [4]]]
```

## Идея решения

Рекурсивный обход с счётчиком оставшейся глубины. Для каждого элемента: если это массив и глубина ещё есть, спускаемся в него с `depth - 1`, иначе кладём элемент в результат.

Результат удобно копить в одном внешнем массиве `out`, а не склеивать массивы на каждом уровне: так меньше копирований.

## Подводные камни

- **Дыры.** `[1, , 3]` содержит дыру на месте индекса 1. Цикл `for (let i = 0; i < arr.length; i++)` прочитает там `undefined` и добавит его в результат, а `.flat()` дыру пропускает. Методы `forEach`, `map`, `filter` дыры пропускают сами, поэтому в решении `forEach`.
- **Проверка массива.** `Array.isArray` надёжнее, чем `instanceof Array`: второе ломается на массивах из другого `iframe` или realm.
- **Спред на больших данных.** `out.push(...flatten(item))` на массиве из сотен тысяч элементов может упасть с `RangeError`: у числа аргументов функции есть предел.
- **Глубина рекурсии.** На очень глубокой вложенности рекурсия упирается в размер стека. Если спросят, переписывается на явный стек.

## Что спросят дальше

- Чем `flatMap` отличается от `map` + `flat()`: это одна операция, и она разворачивает ровно на один уровень.
- Как сделать итеративную версию через стек.
- Как сделать ленивую версию через генератор (`function*` и `yield*`).
