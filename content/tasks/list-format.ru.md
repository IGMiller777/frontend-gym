## Зачем это нужно

«Ann, Bob and 2 others liked this»: такие строки есть в любом интерфейсе со списками людей. Задача проверяет аккуратность с краевыми случаями (0, 1, 2 элемента, лимит, единственное число) и неизменяемость входа.

## Что сделать

`formatList(items, options)` возвращает строку на английском:

- один элемент: `Ann`; два: `Ann and Bob`; больше: `Ann, Bob and Eve`;
- пустые и состоящие из пробелов строки пропускаются; пустой список даёт `''`;
- `unique: true` убирает повторы, `sorted: true` сортирует по алфавиту;
- `limit: n` показывает первые `n` имён и добавляет `and K other` или `and K others`; лимит не меньше длины списка (или `0`) ничего не прячет;
- входной массив не меняется.

## Пример

```ts
formatList(['Ann', 'Bob', 'Eve', 'Max'], { limit: 2 }) // 'Ann, Bob and 2 others'
formatList(['Bob', 'Ann', 'Bob'], { unique: true, sorted: true }) // 'Ann and Bob'
```

## Идея решения

Сначала подготовить список: отфильтровать пустые строки, при необходимости убрать повторы через `Set` и отсортировать копию (`toSorted` с `localeCompare`). Затем разобрать случаи: 0, 1, лимит меньше длины, общий случай с «and» перед последним элементом.

## Подводные камни

- **`sort()` меняет вход.** Нужен `toSorted` или копия.
- **Порядок шагов.** Уникальность до лимита: иначе повторы съедят место.
- **«1 other» и «2 others».** Единственное число легко забыть.
- **Для реального интерфейса** строку собирают через `Intl.ListFormat`, а число через `Intl.PluralRules`: в других языках другие союзы, запятые и формы множественного числа.
