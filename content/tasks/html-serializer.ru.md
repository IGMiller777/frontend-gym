## Зачем это нужно

Превратить дерево в текст с отступами: так работают форматтеры кода, рендер на сервере, генерация писем, отладочный вывод DOM. Задача проверяет рекурсивный обход с глубиной и понимание, почему текст нужно экранировать.

## Что сделать

`serialize(node, indent = '  ')` превращает дерево `{ tag, children }` в HTML-строку:

- открывающий тег, дети и закрывающий тег каждый на своей строке;
- каждый уровень вложенности добавляет один `indent`;
- текстовые дети выводятся строкой с отступом, символы `&`, `<`, `>` экранируются;
- строки соединяются через `\n`.

## Пример

```ts
serialize({ tag: 'ul', children: [{ tag: 'li', children: ['a'] }] })
// <ul>
//   <li>
//     a
//   </li>
// </ul>
```

## Идея решения

Рекурсивная функция `walk(node, depth)` добавляет строки в общий массив: для строки одну строку с отступом `indent.repeat(depth)`, для элемента открывающий тег, затем детей на глубине `depth + 1`, затем закрывающий тег. В конце `join('\n')`.

## Подводные камни

- **Экранирование.** Текст из данных, вставленный как есть, становится разметкой: `<script>` в имени пользователя превратится в XSS. `&` экранируют первым, иначе испортятся уже экранированные последовательности.
- **Склейка строк в рекурсии.** Возвращать строки из рекурсии и склеивать с отступами сложнее и медленнее, чем копить строки в массиве.
- **Глубокие деревья.** Очень глубокое дерево переполнит стек; тогда обход переписывают на явный стек.
