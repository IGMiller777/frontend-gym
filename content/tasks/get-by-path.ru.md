## Зачем это нужно

Путь к данным иногда известен только во время работы: имя поля формы `address.city`, колонка таблицы `user.profile.age`, путь из конфигурации. Для статического пути в коде сейчас пишут `obj?.a?.b ?? fallback` (опциональная цепочка и `??`). Для пути в виде строки нужна функция вроде `_.get` из lodash. Задача проверяет разбор строки, работу с `null` и `undefined` и разницу между «ложным» и «отсутствующим» значением.

## Что сделать

`get(obj, path, defaultValue)`:

- `path` либо строка вида `'a.b[0].c'`, либо массив ключей `['a', 'b', 0, 'c']`;
- если по дороге встретился `null` или `undefined`, вернуть `defaultValue`;
- если итоговое значение `undefined`, тоже вернуть `defaultValue`;
- `0`, `''`, `false` и `null` в конце пути возвращаются как есть.

## Пример

```ts
const data = { users: [{ name: 'Ada' }] }
get(data, 'users[0].name')          // 'Ada'
get(data, 'users[5].name', 'guest') // 'guest'
```

## Идея решения

Сначала превращаем строку в список ключей. Регулярное выражение `/[^.[\]]+/g` находит все куски между точками и скобками: `'a.b[0].c'` даёт `['a', 'b', '0', 'c']`. Индекс остаётся строкой, но для массива это не важно: ключи свойств и так строки.

Дальше идём по ключам. Перед каждым шагом проверяем, что текущее значение не `null` и не `undefined`, иначе чтение свойства бросило бы `TypeError`. В конце подставляем умолчание, только если результат `undefined`.

## Подводные камни

- `return current || defaultValue` ломает ложные значения: `0` превратится в умолчание. Нужна проверка именно на `undefined`.
- Проверка `if (!current)` в цикле прервёт путь на `0` или `''`, хотя у строки можно прочитать `length`.
- Чтение свойств работает и для примитивов: `get({ s: 'abc' }, 's.length')` вернёт `3`, потому что строка временно оборачивается в объект `String`.

## Что спросят дальше

- Чем это отличается от `obj?.a?.b ?? d`: оператор `??` подставит умолчание и для `null`, а `_.get` только для `undefined`.
- Как сделать парный `set(obj, path, value)`, создающий недостающие объекты и массивы.
- Как защититься от ключей `__proto__` и `constructor` в `set` (prototype pollution).
