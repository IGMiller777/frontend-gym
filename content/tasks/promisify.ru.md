## Зачем это нужно

Старые API Node.js и многие библиотеки принимают колбэк `(error, result)` последним аргументом. `promisify` превращает их в функции, возвращающие промис, чтобы писать `await`. В Node.js есть `util.promisify`; задача проверяет, понимаете ли вы, как он устроен, включая `this`.

## Что сделать

`promisify(fn)` возвращает функцию, которая:

- вызывает `fn` с теми же аргументами и добавляет колбэк последним;
- выполняет промис значением `result`, если `error` ложный (`null` или `undefined`), иначе отклоняет его;
- передаёт в `fn` тот же `this`, с которым вызвали её саму;
- работает и с асинхронным, и с синхронным вызовом колбэка.

## Пример

```ts
const readFile = (path: string, cb: (err: Error | null, data?: string) => void) => setTimeout(() => cb(null, 'content'), 10)
const readFileAsync = promisify<string>(readFile)
await readFileAsync('/a.txt') // 'content'
```

## Идея решения

Вернуть обычную (не стрелочную) функцию: только у неё есть свой `this`. Внутри создать промис, колбэк которого вызывает `reject` или `resolve`, и вызвать `fn` с исходным `this` и аргументами плюс колбэк.

## Подводные камни

- **Стрелочная обёртка теряет `this`.** Метод объекта, превращённый в промис, перестанет видеть поля объекта.
- **Ошибка `null` не ошибка.** Проверка `if (error)`, а не `error !== undefined`.
- **Колбэк вызван дважды.** Повторный вызов промис игнорирует, но в реальной библиотеке это признак ошибки.
