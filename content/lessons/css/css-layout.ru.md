## О чём урок

Почти любую раскладку сейчас собирают из двух систем: Flexbox для одной оси (строка кнопок, шапка, элементы карточки) и Grid для двух (страница, галерея, форма в колонки). Здесь главные свойства обеих, частые вопросы («как отцентрировать», «чем `auto-fit` отличается от `auto-fill`», «что значит `grid-column: 1 / 3`»), subgrid и позиционирование.

## Flexbox

Контейнер `display: flex` раскладывает детей вдоль **главной оси** (`flex-direction: row` по умолчанию) и выравнивает по **поперечной**:

- `justify-content` распределяет место по главной оси: `flex-start`, `center`, `space-between`, `space-evenly`;
- `align-items` выравнивает по поперечной: `stretch` (по умолчанию), `center`, `baseline`;
- `gap` задаёт промежутки между элементами, без внешних отступов;
- `flex-wrap: wrap` разрешает перенос на новую строку.

У элемента `flex` это сокращение `flex-grow flex-shrink flex-basis`:

| Запись | Значит | Когда |
|---|---|---|
| `flex: 1` | `1 1 0%`: растёт и сжимается, база ноль | равные колонки независимо от содержимого |
| `flex: auto` | `1 1 auto`: растёт от своего размера | элементы разной ширины делят остаток |
| `flex: none` | `0 0 auto`: не меняет размер | иконка, аватар |
| по умолчанию | `0 1 auto`: не растёт, но сжимается | обычное поведение |

Ловушка: у flex-элемента `min-width: auto`, поэтому длинный текст или таблица не дают ему сжаться меньше содержимого, и строка переполняется. Решение: `min-width: 0` на элементе, который должен сжиматься (например, с `text-overflow: ellipsis`).

## Grid

`display: grid` задаёт строки и колонки. `fr` это доля свободного места.

```css
.page {
  display: grid;
  grid-template-columns: 16rem 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header header"
    "nav    main"
    "footer footer";
  min-block-size: 100dvh;
}
.page > header { grid-area: header; }

.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(14rem, 1fr));
  gap: 1rem;
}
```

- `repeat(auto-fit, minmax(14rem, 1fr))`: столько колонок не уже `14rem`, сколько помещается, без единого медиазапроса. `auto-fill` оставляет пустые колонки, если элементов мало, `auto-fit` их схлопывает, и элементы растягиваются на всю ширину.
- `grid-column: 1 / 3` указывает **линии**, а не колонки: элемент занимает колонки между линиями 1 и 3, то есть **две** колонки. `1 / -1` значит «от первой до последней линии», на всю ширину. `span 2` занимает две колонки от текущего места.

**Subgrid.** `grid-template-columns: subgrid` у вложенного grid берёт колонки родителя. Так заголовки, тексты и кнопки в ряду карточек выравниваются друг с другом, даже если текст разной длины. Поддерживается всеми браузерами с 2023 года.

## Центрирование

```css
/* both axes, inside a container */
.center { display: grid; place-items: center; }

/* horizontally, a block with a known max width */
.content { max-inline-size: 70rem; margin-inline: auto; }
```

`place-items: center` во grid или `justify-content: center; align-items: center` во flex закрывают почти все случаи. Приём с `position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%)` остаётся для наложений поверх контента.

## Позиционирование

| Значение | Поведение |
|---|---|
| `static` | обычный поток, `top` и `z-index` не действуют (кроме flex- и grid-элементов для `z-index`) |
| `relative` | смещение от своего места, место в потоке сохраняется; становится опорой для `absolute`-детей |
| `absolute` | вынут из потока; отсчёт от **содержащего блока**: ближайшего предка с `position` не `static`, а если такого нет, от начального блока размером с окно |
| `fixed` | отсчёт от окна, не прокручивается |
| `sticky` | ведёт себя как обычный, пока при прокрутке не дойдёт до порога (`top: 0`), затем прилипает, **но только в пределах родителя** |

Две частые ловушки:

- Предок с `transform`, `filter`, `perspective`, `contain: paint` или `will-change: transform` становится содержащим блоком и для `absolute`, и для `fixed`. «Фиксированная» модалка внутри анимированного блока перестаёт быть привязанной к окну.
- `sticky` не прилипает, если у какого-то предка `overflow: hidden` или `auto`: прилипание идёт относительно ближайшего прокручиваемого предка. Ещё одна причина: у родителя нет лишней высоты, по которой элемент мог бы «ехать».

## Главное

- Flex для одной оси, Grid для двух; промежутки через `gap`.
- `flex: 1` делит место поровну, `flex: none` фиксирует размер; переполнение лечит `min-width: 0`.
- `repeat(auto-fit, minmax(…, 1fr))` даёт адаптивную сетку без медиазапросов; `grid-column: 1 / 3` это две колонки, линии считаются с 1.
- Subgrid выравнивает содержимое соседних карточек.
- `absolute` отсчитывается от содержащего блока; `transform` у предка меняет его даже для `fixed`; `sticky` ограничен родителем и ломается от `overflow` у предка.
