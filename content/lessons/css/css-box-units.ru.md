## О чём урок

Каждый элемент это прямоугольник из содержимого, внутренних отступов, рамки и внешних отступов. От того, как считаются эти размеры и в каких единицах они заданы, зависят «лишние» пиксели, прыгающая вёрстка на телефоне и масштабирование шрифта. Здесь блочная модель, `box-sizing`, схлопывание отступов, логические свойства и единицы от `rem` до `dvh` и `cqi`.

## Блочная модель и box-sizing

Снаружи внутрь: `margin` → `border` → `padding` → содержимое. По умолчанию (`box-sizing: content-box`) свойство `width` задаёт только ширину содержимого, и итоговая ширина больше: `width + padding + border`. С `box-sizing: border-box` в `width` входят и `padding`, и `border`, поэтому блок с `width: 100%` и отступами не вылезает из родителя. Почти все проекты включают его глобально:

```css
*,
*::before,
*::after {
  box-sizing: border-box;
}
```

## Схлопывание внешних отступов

Вертикальные `margin` соседних блоков в обычном потоке **схлопываются**: между абзацами с `margin-bottom: 24px` и `margin-top: 16px` будет 24 пикселя, а не 40. Так же отступ первого ребёнка может «вытечь» за родителя. Схлопывания нет у flex- и grid-элементов, у элементов с `display: flow-root`, у родителя с `padding` или `border`. Современная практика: задавать промежутки через `gap` у flex и grid, тогда схлопывание не возникает вовсе.

## Логические свойства

Физические `left`, `right`, `top`, `bottom` привязаны к экрану, логические к направлению текста: `inline` это направление строки (слева направо в русском, справа налево в арабском), `block` направление следования блоков.

| Физическое | Логическое |
|---|---|
| `margin-left`, `margin-right` | `margin-inline-start`, `margin-inline-end` |
| `padding-top`, `padding-bottom` | `padding-block` |
| `width`, `height` | `inline-size`, `block-size` |
| `left: 0; right: 0; top: 0; bottom: 0` | `inset: 0` |

С логическими свойствами вёрстка правильно отражается для языков с письмом справа налево без отдельных стилей.

## Единицы длины

| Единица | Относительно чего | Где использовать |
|---|---|---|
| `px` | опорный пиксель (1/96 дюйма) | рамки, тени, мелкие детали |
| `rem` | `font-size` корневого `<html>` | размеры шрифта, отступы: уважает настройку размера шрифта пользователя |
| `em` | `font-size` **самого элемента**; для свойства `font-size` от родителя | отступы, которые растут вместе со шрифтом компонента |
| `%` | зависит от свойства: для `width` и даже для вертикальных `padding` и `margin` это ширина контейнера, для `height` высота контейнера | гибкие размеры |
| `ch` | ширина символа «0» | длина строки текста: `max-inline-size: 65ch` |
| `lh`, `rlh` | высота строки элемента или корня | вертикальный ритм |
| `vw`, `vh` | 1% окна | полноэкранные блоки на десктопе |
| `svh`, `lvh`, `dvh` | малое, большое и текущее окно на мобильных | полноэкранные блоки на телефоне |
| `cqi`, `cqb` | 1% контейнера из container queries | размеры внутри адаптивного компонента |

Частая ошибка с `em`: вложенные `font-size: 1.2em` перемножаются, и шрифт в глубине растёт. Поэтому размеры шрифта задают в `rem`, а `em` оставляют для отступов, которые должны расти с текстом.

**Мобильные `vh`.** На телефоне панель браузера появляется и прячется при прокрутке, и `100vh` равен высоте окна **без** панели: низ блока уходит под неё. `100svh` это высота при видимой панели (контент гарантированно виден), `100lvh` при спрятанной, `100dvh` меняется вместе с панелью. Для полноэкранного первого экрана обычно берут `100svh` или `100dvh`.

## Функции размера

- `min(100%, 70rem)`, `max(…)`, `clamp(1rem, 2.5vw + 0.5rem, 2rem)`: размеры без медиазапросов. `clamp` для «резинового» шрифта стоит сочетать с `rem`, иначе масштабирование страницы не увеличит текст.
- `calc(100% - var(--sidebar))`: арифметика разных единиц.
- `aspect-ratio: 16 / 9`: пропорции блока без старого трюка с `padding-top: 56.25%`.

## Главное

- `box-sizing: border-box` включает `padding` и `border` в `width`; его ставят глобально.
- Вертикальные `margin` в потоке схлопываются; `gap` во flex и grid этого избегает.
- Логические свойства (`margin-inline`, `inset`, `inline-size`) работают и для письма справа налево.
- `rem` для шрифтов, `em` относительно шрифта самого элемента, `%` зависит от свойства.
- На мобильных вместо `100vh` используют `svh`, `dvh` или `lvh`; `cqi` для размеров внутри контейнера.
